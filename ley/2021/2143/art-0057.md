# Art. 57
PROMOCIÓN. Las mutualistas que legalmente se constituyan serán consideradas por el Estado como instituciones de interés social. El Gobierno nacional adoptará las políticas, normas y procedimientos adecuados para asegurar el acceso de las asociaciones mutualistas a los programas y recursos financieros de fomento necesarios para una mayor cobertura y calidad de las actividades que atiendan estas entidades.
