# Art. 31
SISTEMA DE REGISTRO ÚNICO PARA EL SISTEMA FCI. Créase el Sistema de Registro Único para el Sistema FCI. El Gobierno nacional expedirá dentro de un término de doce (12) meses, contados a partir de la entrada en vigencia de la presente ley, los decretos necesarios para ajustar el sistema a que se refiere este y el siguiente artículo de la presente ley y adecuarlo para incluir la Contribución Sabes.
