# Art. 197
DIRECCIÓN ELECTRÓNICA PARA EFECTOS DE NOTIFICACIONES. Las entidades públicas de todos los niveles, las privadas que cumplan funciones públicas y el Ministerio Público que actúe ante esta jurisdicción, deben tener un buzón de correo electrónico exclusivamente para recibir notificaciones judiciales.
Para los efectos de este Código se entenderán como personales las notificaciones surtidas a través del buzón de correo electrónico.
