# Por medio de la cual se modifica el régimen de acceso y ascenso en el sistema general de carrera administrativa, se crea la reserva de plazas para las personas con discapacidad, se establece la gratuidad de la inscripción para este segmento poblacional y se dictan otras disposiciones, o "Ley de Reserva de Plazas para personas con discapacidad" (Ley 2418 de 2024)
