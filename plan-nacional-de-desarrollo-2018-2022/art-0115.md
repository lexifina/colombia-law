# Art. 115
ASOCIACIONES PÚBLICO-PRIVADAS PARA ESCENARIOS PÚBLICOS. Para el trámite de asociaciones público privadas de Iniciativa privada para la construcción, administración, mantenimiento y adecuación de escenarios públicos tales como estadios, coliseos deportivos, centros de convenciones o similares, los tiempos para la evaluación se podrán reducir hasta la mitad.
