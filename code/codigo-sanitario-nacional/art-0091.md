# Art. 91
Los establecimientos industriales deberán tener una adecuada distribución de sus dependencias, con zonas específicas para los distintos usos y actividades, claramente separadas, delimitadas o demarcadas y, cuando la actividad así lo exija, tendrán espacios independientes para depósitos de productos terminados y demás secciones requeridas para una operación higiénica y segura.
