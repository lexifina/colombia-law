# Art. 560
PERITO IMPEDIDO PARA CONCURRIR. Si el perito estuviera físicamente impedido para concurrir a la audiencia pública donde se practicará la prueba, de no hallarse disponible el sistema de audiovideo u otro sistema de reproducción a distancia, esta se cumplirá en el lugar en que se encuentre, en presencia del juez y de las partes que habrán de interrogarlo.
