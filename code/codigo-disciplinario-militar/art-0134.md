# Art. 134
PRINCIPIO DE INTEGRACIÓN. En aquellas materias de procedimiento que no se hallen expresamente reguladas en este código, son aplicables las disposiciones procedimentales del Código Contencioso Administrativo, del Código Penal Militar, del Código de Procedimiento Penal, del Código General del Proceso y del Código General Disciplinario, cuando no sean contrarias a la naturaleza de la acción disciplinaria militar.
