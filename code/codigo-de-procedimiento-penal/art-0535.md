# Art. 535
INTEGRACIÓN. Artículo adicionado por el artículo 11 de la Ley 1826 de 2017. Rige a partir del 12 de julio de 2017. El nuevo texto es el siguiente:> En todo aquello que no haya sido previsto de forma especial por el procedimiento descrito en este título, se aplicará lo dispuesto por este código y el Código Penal.
