# Art. 20
DOBLE INSTANCIA. Las sentencias y los autos que se refieran a la libertad del imputado o acusado, que afecten la práctica de las pruebas o que tengan efectos patrimoniales, salvo las excepciones previstas en este código, serán susceptibles del recurso de apelación.
El superior no podrá agravar la situación del apelante único.
