# Art. 400
TESTIGO SORDOMUDO. Cuando el testigo fuere sordomudo, el juez nombrará intérprete oficial. Si no lo hubiere, el nombramiento recaerá en persona reputada como conocedora del mencionado sistema. Lo anterior no obsta para que pueda estar aco mpañado por uno designado por él.
El testigo y el intérprete prestarán juramento.
