# Art. 160
TÉRMINO PARA ADOPTAR DECISIONES. Salvo disposición en contrario, las decisiones deberán adoptarse en el acto mismo de la audiencia. Para este efecto el juez podrá ordenar un receso en los términos de este código.
Cuando deban adoptarse decisiones que se refieran a la libertad provisional del imputado o acusado, el funcionario judicial dispondrá máximo de tres días hábiles para realizar la audiencia respectiva.
